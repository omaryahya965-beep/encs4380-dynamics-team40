How to estimate the parameters

First-order step: Find the final output KA. For a unit step, K is the final output. The time at which the response first reaches 63.2% of the final change is approximately τ.

First-order sine: Use the input and output phase shift to estimate τ = tan(|φ|)/ω; then K = output amplitude × √(1 + (ωτ)²) for a unit-amplitude sine.

Second-order step: Use overshoot OS to estimate ζ, then peak time tp to estimate ωn. For the underdamped case: ζ = −ln(OS) / √(π² + ln²(OS)); ωn = π / (tp√(1 − ζ²)). Non-oscillatory curves require different estimation methods.

The noise is generated for display and is not used to evaluate the theoretical model curves.
